# 🐍 Python Code Tools Suite

A comprehensive web-based toolkit for Python developers with essential utilities for code formatting, validation, conversion, parsing, generation, and debugging.

## 🛠️ Tools Included

### 1. **Code Formatter**
Format and beautify your Python code with options for:
- Normalize indentation (4 spaces)
- Remove trailing whitespace
- Add spacing around operators

### 2. **Code Validator**
Validate Python syntax and find common issues:
- Check for mismatched parentheses and brackets
- Detect missing indentation after colons
- Identify missing imports
- Report warnings and errors

### 3. **Type Converter**
Convert between Python data formats:
- JSON ↔ Dictionary
- JSON ↔ List
- CSV ↔ JSON
- And more!

### 4. **Code Parser**
Analyze Python code structure and extract:
- Class definitions
- Function definitions
- Import statements
- Line numbers for easy navigation

### 5. **Boilerplate Generator**
Generate Python code templates for:
- Class definitions (with `__init__`, `__str__`, `__repr__`)
- Functions (with docstrings)
- Decorators
- Custom exceptions
- Context managers
- Main scripts (with logging)

### 6. **Debug Helper**
Generate debug code snippets:
- Print debugging statements
- Logging setup and usage
- Try-except error handling
- Traceback information

## 📖 How to Use

1. Open `python-tools.html` in your browser
2. Select the tool you need from the navigation menu
3. Enter your input (code, data, etc.)
4. Click the action button to process
5. Copy the output with the clipboard button

open python-tools.html

## 🐛 Known Limitations

- Validator is pattern-based, not a full Python parser
- Type converter uses JSON parse for simplicity
- Parser extracts basic structure only
- No actual code execution (for security)
